# HT-024TeamAlpha1
Baramati Traffic Sentinel is a smart traffic monitoring and prediction system that analyzes traffic conditions and predicts congestion before it happens.

The system uses a rule-based AI engine to detect:

🚗 Traffic Jams

🚧 Bottlenecks

🚦 Signal Overload

🚑 Emergency Route Optimization

It provides a real-time interactive dashboard with map visualization and traffic analytics.
